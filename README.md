# 불장연구소

뉴스·광고·수급을 보고 직접 매수·매도하는 무한 시즌 투자 웹게임입니다.
시작 시드는 적습니다. 알바로 돈을 벌고, 회사를 상장해 광고를 걸거나 서로의 주식에 투자하세요.

별도 설치 없이 `index.html`을 브라우저에서 열면 플레이할 수 있습니다. GitHub Pages 같은 정적 호스팅을 전제로 합니다.

플레이: https://pixco-dev.github.io/rage-cat/

## 로그인

- 회원가입 / 로그인은 이 브라우저의 `localStorage`에만 저장됩니다.
- 비밀번호는 SHA-256 + salt로 해시한 뒤 저장하며, 평문은 남기지 않습니다.
- 비밀번호는 공유 시장 JSON에 절대 올라가지 않습니다.
- 아이디·닉네임이 시장 안 투자자 이름과 창업자 명의가 됩니다.

## 전 세계 단일 시장

솔로와 멀티의 구분이 없습니다. 로그인 후 난이도를 고르고 **시장 입장**하면 모두가 같은 세계에 들어갑니다. 방 코드·방 링크는 없습니다.

다른 플레이어가 세운 회사, 광고, 시세가 같은 목록에 나타납니다. 공유 스냅샷은 JSONBlob에 저장되며, 브라우저가 몇 초마다 불러옵니다.

## 교시 정산 (한국 표준시)

장치 시계가 아니라 공개 표준시 API(WorldTimeAPI → timeapi.io 등)에서 받은 **Asia/Seoul** 시각을 씁니다.

수업이 끝나는 시각에 시장이 한 번 정산됩니다.

- 09:20, 10:20, 11:20, 12:20, 14:00, 15:00, 16:00

주말과 평일 16:00 이후는 **장 마감 (수업 시간 외)** 이며, 다음 평일 09:20까지 거래가 닫힙니다. `lastSettledPeriodId`에 날짜+교시가 남아 같은 교시를 두 번 정산하지 않습니다.

## 회사 · 광고 · 채팅

- 계정당 회사 1곳. 시드 현금으로 상장하고 창업 주식을 보유합니다.
- **매수는 가격을 밀고, 매도는 누릅니다.**
- 창업자는 슬로건과 함께 **직접 고른 광고 이미지**를 올릴 수 있습니다. 게임 파일에 샘플 사진을 넣지 않습니다. 이미지가 없으면 글만 게시됩니다.
- 채팅방을 만들고 같은 시장에서 대화할 수 있습니다. 최근 메시지 50개가 공유됩니다.

## 시즌

12주가 끝나면 다음 시즌이 이어집니다. 현금·보유·설립 회사는 유지됩니다.

## 실행

브라우저에서 `index.html`을 엽니다. GitHub Pages에 올리면 전 세계 단일 시장이 동작합니다.
