# 불장연구소

뉴스·광고·수급을 보고 직접 매수·매도하는 무한 시즌 투자 웹게임입니다.
시작 시드는 적습니다. 알바로 돈을 벌고, 회사를 상장해 광고를 걸거나 서로의 주식에 투자하세요.

별도 설치 없이 `index.html`을 브라우저에서 열면 플레이할 수 있습니다. GitHub Pages 같은 정적 호스팅을 전제로 합니다.

## 로그인

- 회원가입 / 로그인은 이 브라우저의 `localStorage`에만 저장됩니다.
- 비밀번호는 SHA-256 + salt로 해시한 뒤 저장하며, 평문은 남기지 않습니다.
- 아이디·닉네임이 방 안 투자자 이름과 창업자 명의가 됩니다. 새로고침해도 세션이 유지됩니다.

## 멀티플레이 (PeerJS)

서버를 직접 돌리지 않습니다. 방은 [PeerJS](https://peerjs.com/) 공용 클라우드 브로커로 연결됩니다.

- **방 만들기**: 5자리 코드가 생깁니다. 참가자에게 공유하세요.
- **코드로 참가**: 같은 코드로 입장합니다. 같은 아이디의 중복 입장은 거절됩니다.
- 방장이 시세·뉴스·주간 마감의 권한을 가집니다.
- PeerJS가 실패하거나 연결이 끊기면 솔로 + 봇 시장으로 넘어가고 토스트로 알립니다.

인터넷이 필요합니다. 공용 PeerJS 브로커를 쓰므로 방 코드는 비밀이 아닙니다.

## 솔로

방에 들어가지 않으면 봇 투자자 3–6명이 가짜 회사를 상장하고 사고팝니다. 목록에 **봇**으로 표시됩니다.

## 회사 · 광고 · 가격

- 계정당 회사 1곳. 시드 현금으로 상장하고 창업 주식을 보유합니다.
- 다른 사람(또는 봇)이 그 주식을 사고팔 수 있습니다.
- **매수는 가격을 밀고, 매도는 누릅니다.** 거래 규모 대비 유통 주식 수에 비례합니다.
- 창업자는 주간 광고(슬로건 + 성장/배당/안정 주장)를 집행할 수 있습니다. 관심(매수세)을 부르지만, 허풍이 들키면 신뢰와 주가가 같이 꺾입니다.
- 광고는 정보가 아니라 캠페인입니다. 다음 주 수익률을 보장하지 않습니다.

## 시즌

12주가 끝나면 다음 시즌이 이어집니다. 현금·보유·설립 회사는 유지되고, 뉴스 덱만 새로 섞입니다.

## 실행

브라우저에서 `index.html`을 엽니다. GitHub Pages에 올리면 멀티플레이 방이 동작합니다.
