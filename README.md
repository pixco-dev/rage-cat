# 불장연구소

뉴스와 산업 전망을 분석해 12주 동안 직접 매수·매도하는 전략 투자 웹게임입니다.
시작 시드는 적습니다. 알바로 돈을 벌고, 정보를 사서 방향을 열어야 합니다.

## 주요 콘텐츠

- 6개 투자 자산, 24개 시장 이벤트
- 뉴스는 업종 힌트만 주고 승패 종목은 공개하지 않음
- 기본 전망은 미확인. 리서치·제보·퀴즈로만 방향 확인
- 주간 에너지로 돌아가는 노동 알바 6종
- 정보 수집 4종 (소문, 익명 제보, 업종 브리핑, 유료 리포트)
- 미니게임 5종 (타이핑, 타이밍, 기억, 퀴즈, 루머 vs 팩트)
- 3개 난이도, 6개 미션, 9개 업적
- 포트폴리오·위험도·거래 기록·최고 수익률 저장
